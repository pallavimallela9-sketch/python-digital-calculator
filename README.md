# Digital Calculator

This Python program is a menu-driven digital calculator that performs different arithmetic operations and maintains a history of previous calculations.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Power calculation
* Calculation history
* Clear calculation history
* Division-by-zero validation
* Invalid input handling
* Menu-driven interface

## Technology Used

* Python

## Concepts Used

* Lists
* `while` loop
* `if-elif-else`
* Exception handling
* Functions such as `float()`
* Arithmetic operators
* String formatting
* List operations
* User input
